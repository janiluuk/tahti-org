Keeping it honest

Hard to game, by construction.

Passive earns nothing

Counted once

The guarantee

It can never be turned against you.

If prices ever crept up
fork it and run it your way
If ads or data-selling slipped in
the constitution forbids it — public source can't hide it
If we were sold, or folded
the platform lives on; export everything
If a feature you rely on was removed
keep it alive in a fork

There is no version of this where you're trapped anywhere but your studio.

Governance

Not a company you upload to — an association you own.

✦One member, one vote. Proposals run continuously; formal decisions at the AGM.
✦Core promises locked — no cut of fan support, no data sold, no ads — changeable only by a two-thirds vote, 60 days' notice.
✦No exit, no shareholders. Surplus flows to artists; the board becomes artist-majority as it matures.
