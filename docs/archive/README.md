# Archive

Historical planning specs, superseded by current status docs. Each file already
carries its own "historical planning spec" banner pointing at the doc that
replaced it (usually [`../project-roadmap.md`](../project-roadmap.md)). Kept
for original implementation recipes and a couple of still-useful reference
sections (see `delivery-phases.md`'s Scaling reference / Rollback procedure).

Do not treat anything here as current status. Do not add new files here —
this is a landing spot for docs that were already stale when moved, not a
place to file new work.

- `delivery-phases.md` — the original phase-by-phase delivery plan (predates
  and doesn't match `project-roadmap.md`'s own Phase 0–10 numbering).
- `phase-1.md` … `phase-12.md` — per-phase implementation specs written
  prospectively, before each phase shipped.
