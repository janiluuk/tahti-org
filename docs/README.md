# Docs map

Short index for humans and agents. Deep rules live in linked files.

## Aim

Build and operate **Tahti ry**’s AGPL nonprofit broadcasting platform: always-on
artist channels, anonymous listening, transparent surplus → artists. Hosted
product is `apps/web`; **Nuclear** (separate repo, `beta.tahti.live`) is the
listen/studio client on the same API; public docs at `https://api.tahti.live/api`.

## Removed on purpose

Dated HTML/PNG mockup packs, `_archive/` design drafts, point-in-time UX audits,
and session worklogs were deleted so agents stop treating them as current truth.
Visual truth is **live UI + e2e screenshots + `@tahti/ui`**.
