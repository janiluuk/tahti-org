# Screenshots

From the [Tahti Player](https://github.com/janiluuk/tahti-player) web client (`tahti-web`, live on [tahti.live](https://tahti.live)), which talks to this API. The images load from that repo, so they follow its latest captures; light and dark versions follow your GitHub theme. Every screen is indexed in its [full view guide](https://github.com/janiluuk/tahti-player/blob/master/packages/tahti-web/docs/VIEW-GUIDE.md).

| Screen | What it shows |
| --- | --- |
| [Listen home](#listen-home) | Library favorites, Tahti Radio, discover |
| [Channel](#channel-live--archive) | Live stage, pinned archive, chat rail |
| [Fan subscribe](#fan-subscribe) | Fan membership tiers (Stripe Checkout on the live API) |
| [Studio home](#studio-home) | Go Live, schedule, music, upload, albums |
| [Go Live](#go-live) | Broadcast wizard: Connect → Live → Multistream |
| [Playlists](#playlists) | Archive tracks and releases |
| [Channel design](#channel-design) | Look, 24/7 radio, profile, domain |
| [Board admin](#board-admin) | Health, activity, moderation |
