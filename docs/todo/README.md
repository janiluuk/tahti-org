# Active todos

Open work only. One file per in-progress task.

When a task ships: append a compact dated section to [HISTORY.md](./HISTORY.md), then delete
the file here. Leftovers go to `docs/remaining-work.md` or a new slim todo. Session worklogs
under `docs/worklogs/` follow the same rule.

Do not keep finished checklists in this folder. See `CLAUDE.md` and `.cursor/rules/todo-history.mdc`.
